# Dashboard de Desempenho de Vendas

Este repositório contém um dashboard de vendas desenvolvido no Excel para o desafio de organização e visualização de dados. O objetivo do projeto foi estruturar dados brutos de faturamento e transformá-los em um relatório visual claro para tomada de decisões.

## 📊 Estrutura do Projeto
O arquivo `.xlsx` foi organizado seguindo boas práticas de divisão de escopo:
- **Bases:** Contém os dados brutos de vendas, produtos, regiões e os cálculos automatizados de faturamento por linha.
- **Dashboard:** Painel visual isolado focado na análise do faturamento por região e produto.

## 🛠️ Tecnologias Utilizadas
- Microsoft Excel / M365 Online
- Fórmulas de multiplicação e consolidação de dados
- Gráficos de colunas para análise de performance

## 🚀 Como reproduzir
1. Baixe o arquivo `Book.xlsx` presente neste repositório.
2. Abra no Microsoft Excel ou Google Planilhas.
3. Navegue entre as abas inferiores para conferir a separação entre a base de dados e a interface visual.
